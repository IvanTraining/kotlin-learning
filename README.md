# Recipe Book (Книга рецептов)

## Краткое описание проекта
**Recipe Book** — это бэкенд-приложение для ведения кулинарной книги.
Проект позволяет пользователям находить рецепты по заданным критериям, сохранять их в избранное, 
добавлять свои рецепты (с изображениями по желанию) ,а также делиться кулинарными шедеврами.

**Стек технологий:** Kotlin, Spring Boot, PostgreSQL, Gradle.


## Целевая аудитория
Приложение предназначено для пользователей которым интересна и нравится тема приготовления пищи,
а также тем, кто просто желает научиться готовить.
1. **Новичок** : Не умеет готовить, боится испортить продукты. 
                 Нужны четкие пошаговые инструкции с фото.
                 Есть возможность фильтровать простейшие рецепты с таймером готовки до 30мин.
2. **Опытный кулинар** : Имеет много своих рецептов, записанных на бумаге. 
                         Непротив делиться ими с друзьями по почте.
3. **Обычный человек умеющий готовить, с высокой занятостью** : 
        Важно быстро и вкусно приготовить используя фильтр по ингридиентам, типам блюда, времени приготовления.
        Актуально использование функционала ИЗБРАННОЕ.


## MVP
В первую версию (MVP) войдут следующие функции:
1. Аутентификация: Регистрация и вход.
2. Каталог рецептов: CRUD-операции для рецептов (создание, чтение, обновление, удаление). 
                     Доступно только авторам для изменения/удаления.
3. Поиск и фильтрация: Поиск по названию, ингредиентам,
                       времени приготовления, 
                       категория блюда (суп, горячее, салат, веганское, выпечка, десерт, закуска)
4. Избранное: Добавление и удаление имеющихся в приложении рецептов из списка избранных.
5. Загрузка изображений: Сохранение картинок для рецептов и шагов (локально). 
6. По возможности. Отправка (имитация отправки) выбранного рецепта на email .

## Описание сущностей приложения. 
## Классы, ENUM. (функционал отправки Email под вопросом. В тему развития продукта)

| Сущность | Описание | Поля |
| :--- | :--- | :--- |
| **User** | Пользователь | `id`, `login`, `name`, `second_name`, `password`, `created_at`, `mail` |
| **Recipe** | Рецепт | `id`, `name`, `description`, `cooking_time`, `created_at`, `main_image` |
| **Ingredient** | Ингредиент | `id`, `name` |
| **Recipe_Ingredient** | Связь рецепта и ингредиента | `recipe_id`, `ingredient_id`, `count`, `unit` |
| **Recipe_Step** | Шаг рецепта | `id`, `recipe_id`, `step_number`, `description`, `image` |
| **Category** | Категория блюда | `id`, `name` |
| **Recipe_Category** | Связь рецепта и категории | `recipe_id`, `category_id` |
| **Favorite** | Избранное | `user_id`, `recipe_id` |
| **Email_Task** *(Post-MVP)* | Задача на отправку email | `id`, `user_id`, `recipe_id`, `mail` |



## Архитектурное видение приложения. (функционал отправки Email под вопросом. В тему развития продукта)
[Посмотреть архитектурную схему](docs/images/architecture.jpg)
1. Слой API (Controllers):
AuthController (регистрация/логин).
RecipeController (CRUD рецептов, поиск, фильтры).
FavoriteController (добавление в избранное).
**ShareController** (отправка на email). - под вопросом.

2. Слой Бизнес-логики (Services):
RecipeService (логика работы с рецептами, обработка Sequence/Collections для фильтрации).
**EmailService** (под вопросом)
ImageService (сохранение картинок).

3. Слой работы с БД (Repositories)

4. База данных (PostgreSQL)

5. Внешние сервисы (ExternalService): для отправки писем. (под вопросом)
